DSH Recovery Center

Use these safe, reversible checks when DSH cannot start or a plugin causes trouble. Your chats and workspace are not deleted.

1. Diagnose

Check plugin compatibility, Safe Mode, and host-package identity before making changes.

2. Repair runtime links

Restores the selected DSH runtime's shared package identity, then restarts DSH. This keeps plugins installed.

3. Restart only

Restart DSH without changing plugins or runtime files.

Safe Mode

Safe Mode keeps chats and plugin packages, but temporarily disables non-core plugins after a crash loop.

If this does not fix it

Open Plugin Manager to disable a recently added community plugin, or use the wrapper's Safe Mode when it is available.
